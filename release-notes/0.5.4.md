MatrixGram 0.5.4

- Автоматическое уведомление о новой версии и кнопка обновления в приложении.
- Восстановление последнего списка комнат при запуске; защищённый кеш последних 50 сообщений с именами отправителей и курсором истории, включая открытые E2EE-чаты.
- Загруженные изображения и аватары сохраняются между запусками в защищённом медиа-кеше.
- На Android убрана постоянная панель быстрых действий с 👍. Меню сообщений открывается кнопкой «···».
- Уведомления Windows содержат переход в свой чат с показом окна приложения. Добавлены protocol activation и single instance для сохранённых уведомлений.

Автотесты проверяют восстановление без сети, защиту кеша, integrity медиа, маршрутизацию уведомлений и сенсорное меню. Реальный клик в центре уведомлений Windows и обновление установленной версии на Windows/Android ещё не подтверждены. Для регистрации переходов рекомендуется Windows installer. Новые файлы попадают в кеш после их загрузки; ранее не загруженные вложения требуют сети.
