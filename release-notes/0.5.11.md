Опросы из Element теперь отображаются в переписке. Можно выбрать варианты, проголосовать, изменить или отозвать свой голос. Поддержаны несколько вариантов, скрытые результаты до завершения и закрытые опросы.

Голоса загружаются через Matrix relations; при большом опросе доступна кнопка «Загрузить ещё голоса». Отправка в E2EE проходит через шифрование SDK. Повтор после сетевой ошибки сохраняет transaction ID. Опросы включены в защищённый кеш сообщений.

Создание и пересылка опросов пока не добавлены. Прошли четыре целевые проверки: две unit, одна browser на desktop/phone и одна native plain/E2EE. Реальная переписка с Element и физический Android отдельно пока не проверены.
