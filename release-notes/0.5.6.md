# MatrixGram 0.5.6

- Windows: первоначальная настройка для общей группы MatrixGram с дочерними WebView2 и суммарной памятью в диспетчере задач, включая сортировку по памяти. Процессы и их изоляция сохраняются.
- Настройка доступна при установке и в настройках приложения. Требуются согласие и UAC; временное доверие сертификату удаляется. При обычных обновлениях повторная настройка не нужна.
- Добавлена кнопка «Тестовое уведомление» без отправки сообщений другим пользователям.
- Автотесты проверяют сохранение каталога при обновлении, реальные NSIS hooks и состояние настройки.

На Windows 11 пользователь подтвердил обычную установку локального 0.5.6, общую группу, сохранение чатов и переход по тестовому системному уведомлению. Перезагрузка и Windows 10 ещё не проверены. Android не получает Windows-компоненты.
