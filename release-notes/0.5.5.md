MatrixGram 0.5.5

- Windows: в настройках добавлен раздел «Память приложения» с общей ОЗУ MatrixGram и его WebView2.
- Доступны количество процессов и таблица PID/памяти каждого процесса.
- Замер обновляется раз в 5 секунд при открытых настройках, приостанавливается для скрытого окна и прекращается после закрытия настроек.
- Недоступные процессы и ошибки измерения показываются явно.

Показана частная резидентная ОЗУ; общая видеопамять в сумму не входит. Процессы других приложений исключаются. Объединение ветки Windows Task Manager остаётся открытой проблемой Tauri/WebView2 — этот выпуск добавляет согласованный общий счётчик внутри MatrixGram. Android Windows-счётчик не показывает.
