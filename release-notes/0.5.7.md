MatrixGram 0.5.7

- Отправка и скачивание файлов до 500 МиБ (524 288 000 байт), включая зашифрованные вложения. Лимит соответствует текущему серверу, серверные настройки не менялись.
- Большие файлы передаются частями с прогрессом и отменой. Весь файл не загружается в память WebView; можно переключать чаты во время передачи.
- Сохранение через системный диалог; проверка целостности E2EE до сохранения. На Windows ошибки и отмена не заменяют уже существующий файл.
- Android «Поделиться» передаёт файлы через нативные дескрипторы, без большого base64 в Kotlin/JavaScript.

Предпросмотр, аватары и запись голоса ограничены 25 МиБ. Для больших файлов нужно свободное место на диске; возобновления после закрытия клиента нет. Проверены локальные потоковые тесты и автоматические сценарии клиента. Реальная передача большого файла через Matrix, Windows UI установленной версии и SAF/Share на телефоне пока отдельно не подтверждены.
