# MatrixGram 0.5.2

Matrix-клиент для Windows 10/11 x64 и Android на Tauri 2, React/TypeScript, Rust Matrix SDK 0.19.1, SQLite и Zustand. Сервер по умолчанию: **https://matrix.mad-frog.ru**. Интерфейс следует присланному примеру Telegram Desktop; действие управления папками называется **ПАПКИ**.

Это ранняя сборка. Точный статус артефактов и проверок: [PROGRESS.md](PROGRESS.md).

## Подписанные обновления 0.5.2

В настройках добавлены проверка, скачивание и установка новых версий из [GitHub Releases](https://github.com/VirusGrip/MatrixGram/releases). Windows использует Tauri updater; Android передаёт проверенный APK системному установщику с подтверждением пользователя. Первая установка 0.5.2 выполняется вручную: в 0.5.1 updater ещё отсутствует. Черновик сохраняется перед установкой; звонки и незавершённые отправки блокируют её.

GitHub Actions собирает и подписывает релизы по тегу `vX.Y.Z`, публикует оба пакета, source ZIP и `latest.json`. Новые версии по-прежнему компилируются, но это выполняется CI. [Инструкция выпуска и обновления](docs/UPDATES.md). Статус первого реального CI-запуска и проверки на устройствах — в PROGRESS.md.

## Оптимизация из 0.5.1

Кеш проекции истории с освобождением через WeakMap, поиск/фильтры по индексам и Set, переиспользование DateTimeFormat. Неизменившаяся открытая переписка не перерисовывается из-за sync других чатов; read receipts, ответы и участники находятся через Map. Одновременные запросы одной страницы истории объединяются отдельно для каждой сессии. SQLite переиспользует подготовленные запросы в пакетных транзакциях.

Нагрузочные сценарии: 5 000 чатов / 60 000 событий / серия sync при CPU ×4; превью 200 E2EE-комнат с двумя фоновыми запросами; 100 000 событий SQLite, повторы и конкурентные записи. Методика и фактические результаты: [PERFORMANCE.md](docs/PERFORMANCE.md).

## Диалоги и сообщения

- После подключения ключей список чатов показывает последнее доступное сообщение; недоступный ключ обозначается отдельно. Превью E2EE остаются только в памяти.
- Личные диалоги используют фото собеседника; комнаты и группы сохраняют свой аватар.
- ПКМ по сообщению → «Выделить сообщение» → флажки → «Переслать выбранные». До 100 загруженных сообщений за раз, в хронологическом порядке; при ошибке повторяется оставшаяся часть.
- ПКМ по чату → «Закрепить чат» или «Подписать контакт». Подпись доступна также в профиле пользователя, видна только текущему аккаунту на устройстве; имя в Matrix не меняется.
- Исправлено дублирование переписки при переключении с открытой информацией о комнате и перехват кликов невидимыми кнопками сообщения.

## Возможности клиента

- Фото, видео, аудио и файлы до 25 МБ: отправка, просмотр, системное сохранение, очередь, прогресс, отмена и повтор. Загрузки файлов продолжаются при переходе в другой чат.
- Голосовые: настоящий MediaRecorder, индикатор уровня, пауза, продолжение, отмена и воспроизведение.
- Профили и настоящие аватары, изменение своего имени/фото, блокировка и разблокировка пользователя.
- Участники, приглашения, права администратора/модератора, исключение и блокировка, название/описание/фото комнаты, выход, публичный каталог. Канал создаётся с отправкой только администраторами.
- Пересылка, закреплённые сообщения, безопасное форматирование Markdown/Matrix HTML, mentions полным Matrix ID, typing и отметки прочтения. Для обычных комнат — поиск по серверной истории с переходом к результату; для E2EE — поиск в загруженном тексте.
- Несколько сохранённых аккаунтов, переключение с очисткой UI, список устройств, переименование и отзыв другой сессии с серверным подтверждением паролем, если оно требуется.
- Уведомления, звук, отключение уведомлений комнаты, масштаб 85–125%, фон, Windows tray и автозапуск. Кнопка закрытия окна завершает приложение; для работы в фоне используйте «Свернуть в трей».
- Реальные звонки 1:1 WebRTC: аудио/видео, mute, выбор устройств и демонстрация экрана, когда её поддерживает WebView. TURN берётся из стандартного Matrix API. Групповых звонков нет; реальный TURN и совместимость с Element ещё не проверены.
- Android bridge: Keystore, системный Back, разрешения микрофона/камеры/уведомлений, системное сохранение файлов и получение «Поделиться». Наличие исходников не означает проверки на телефоне; см. статус APK.

## Ключи, поиск и ПАПКИ

«Открыть зашифрованные комнаты» остаётся сбоку. Вход не требует recovery key. Доступны ручное включение E2EE, восстановление существующего secret storage, импорт и зашифрованный экспорт ключей. Новые комнаты/DM по умолчанию без шифрования; при создании комнаты можно явно выбрать E2EE. Шифрование и проверку целостности выполняет SDK. Автоматическое создание backup/cross-signing отключено. SAS/QR-верификации и создания новой серверной резервной копии в UI пока нет.

Поиск людей использует каталог Synapse по имени/фамилии/Matrix ID. ПАПКИ сохраняют названия, состав, порядок и фильтр непрочитанных локально для аккаунта. Их синхронизации между устройствами пока нет.

Токены и пароль SDK store не передаются в WebView. Windows использует DPAPI; Android — AES-GCM с Android Keystore. E2EE-история не пишется в открытый UI-кеш. Обычный кеш сохраняется после выхода. Конфигурация Synapse, PostgreSQL и TURN не менялась.

## Сборки и разработка

Актуальные EXE/NSIS/APK перечислены в [PROGRESS.md](PROGRESS.md). Старые 0.1–0.5.0 сохранены отдельно. Сборки Windows без цифровой подписи; архив исходников не содержит бинарников и токенов.

Нужны Node.js 24, Rust 1.99.1, Microsoft C++ Build Tools и Windows SDK; для запуска — WebView2 Runtime.

```powershell
npm ci
npm run tauri -- dev
npm run build
npm test
npm exec -w @matrixgram/client -- playwright install chromium
npm run test:e2e
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
npm run check:policy
./scripts/build-windows.ps1
```

`npm run dev` открывает веб-оболочку без Rust, поэтому вход в ней отключён. Тестовые данные подключаются только тестовым IPC.
