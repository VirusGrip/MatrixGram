# MatrixGram 0.5.12

Matrix-клиент для Windows 10/11 x64 и Android на Tauri 2, React/TypeScript, Rust Matrix SDK 0.19.1, SQLite и Zustand. Интерфейс следует присланному примеру Telegram Desktop; действие управления папками называется **ПАПКИ**.

В [0.5.10](https://github.com/VirusGrip/MatrixGram/releases/tag/v0.5.10) шапка чата компактнее: звонки, поиск, информация и ключи перенесены в меню ⋮, постоянной надписи о шифровании нет. На Android личная переписка занимает ширину экрана, без боковых аватаров и «···» у сообщений; действия доступны долгим нажатием. Поле ввода скруглено, микрофон сменяется отправкой. Windows сохраняет боковые аватары. Шифрование и выбранные цвета/фон сохранены.

С 0.5.9 выбор файла сначала прикрепляет его к черновику: напишите подпись и нажмите «Отправить». Файл сверху, текст снизу — одно сообщение, включая E2EE и файлы до 500 МиБ. Убрана постоянная панель «Отправлено / Закрыть»; прогресс и повтор находятся в исходящем сообщении. Для нескольких файлов подпись у последнего; выбранные вложения сохраняются при переключении чатов, пока приложение открыто. Android «Поделиться» тоже сначала заполняет черновик.

Свои сообщения справа, собеседник слева; выделение не сдвигает сообщения, поле ввода растёт. Установленная Windows 0.5.10 и физический Android пока отдельно не проверены.

Это ранняя сборка. Точный статус артефактов и проверок: [PROGRESS.md](PROGRESS.md).

0.5.12: закрепы над перепиской с переходом к сообщению, полный каталог Unicode Emoji 17 с локальной графикой/поиском/оттенками кожи, увеличение и перемещение фото. Выбор эмодзи остаётся открытым после вставки, закрывается нажатием снаружи или на кнопку эмодзи. На Windows крестик скрывает клиент в трей, непрочитанные отмечаются числом на значке панели задач и трея; завершение — через меню трея.

Графика эмодзи: [Twemoji](https://github.com/jdecked/twemoji), Twitter и участники, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Изображения не изменены. Данные Unicode — [Unicode License](https://www.unicode.org/license.txt); лицензии и атрибуция включены в пакет.

[0.5.11](https://github.com/VirusGrip/MatrixGram/releases/tag/v0.5.11) добавляет отображение Matrix-опросов из Element, выбор одного/нескольких вариантов, изменение и отзыв своего голоса, результаты и завершение. Скрытые результаты открываются после завершения; ответы подгружаются через relations. Создание опросов в этом выпуске не добавлено.

## Общий расход памяти 0.5.5

Windows: Настройки → Память приложения. Показана сумма частной ОЗУ MatrixGram и всех его дочерних процессов, включая WebView2, с раскрываемой таблицей PID/памяти. Замер обновляется раз в 5 секунд при открытых настройках и приостанавливается для скрытого окна. Недоступные данные отмечаются как неполный замер; старый результат не выдаётся за свежий при ошибке.

В 0.5.6 добавлена [настройка группировки WebView2 внутри MatrixGram](docs/WINDOWS_PROCESS_GROUPING.md) через package identity. Пользователь подтвердил группировку, сохранение чатов и переход по системному уведомлению после обычной установки локального 0.5.6 на Windows 11. Первая настройка требует согласия и UAC; для обычных обновлений повторять её не нужно. [0.5.6 опубликована](https://github.com/VirusGrip/MatrixGram/releases/tag/v0.5.6). Android Windows-счётчик и настройку не показывает.

## Кеш и уведомления 0.5.4

При запуске автоматически проверяется новая версия; при наличии появляется кнопка «Обновить». Проверка повторяется не чаще раза в четыре часа, установка остаётся по нажатию пользователя. Настройки → Обновления доступны также для ручной проверки.

Список комнат восстанавливается из последнего успешного sync. В каждой открытой или синхронизированной комнате сохраняются последние 50 сообщений, профили отправителей и курсор истории; они доступны до подключения к серверу. Снимки защищены DPAPI/Android Keystore, включая расшифрованную E2EE-историю после подключения ключей. Уже загруженные изображения и аватары сохраняются в защищённом SDK media store (256 МиБ, удаление давно неиспользуемого через 60 дней). Это не предварительная загрузка всех вложений.

В установленной Windows-версии уведомление содержит переход в свой чат: окно показывается, снимается сворачивание, выбирается комната. Для сохранённых уведомлений используется зарегистрированный установщиком протокол `matrixgram://`; переход ожидает восстановления сессии и не открывает чат чужого аккаунта. Автотесты проверяют маршрутизацию через IPC. Пользователь подтвердил открытие чата по тестовому системному уведомлению после локальной установки 0.5.6; установленная 0.5.7 отдельно не проверена. В Android постоянно видимая панель с 👍 заменена кнопкой «···», реакции доступны в меню сообщения.

## Имена, переключение чатов и приглашения 0.5.3

Известные SDK имена и аватары отправителей передаются вместе с историей и sync. Открытие чата не запрашивает полный список участников. Свежая страница истории повторно используется 60 секунд; sync продолжает получать сообщения и изменения имён/прав. После подключения ключей выполняется новая загрузка.

Приглашения без сообщений показываются над списком чатов, первыми во «Всех чатах» и в разделе «Новые». Доступны имя пригласившего, принятие и отклонение. Системное уведомление отправляется один раз для ожидающего приглашения, включая найденное после входа или переподключения; требуются разрешение ОС и работающий клиент. Фонового push на закрытом Android пока нет.

## Оптимизация из 0.5.1

Кеш проекции истории с освобождением через WeakMap, поиск/фильтры по индексам и Set, переиспользование DateTimeFormat. Неизменившаяся открытая переписка не перерисовывается из-за sync других чатов; read receipts, ответы и участники находятся через Map. Одновременные запросы одной страницы истории объединяются отдельно для каждой сессии. SQLite переиспользует подготовленные запросы в пакетных транзакциях.

Нагрузочные сценарии: 5 000 чатов / 60 000 событий / серия sync при CPU ×4; превью 200 E2EE-комнат с двумя фоновыми запросами; 100 000 событий SQLite, повторы и конкурентные записи. Методика и фактические результаты: [PERFORMANCE.md](docs/PERFORMANCE.md).

## Диалоги и сообщения

- После подключения ключей список чатов показывает последнее доступное сообщение; недоступный ключ обозначается отдельно. В 0.5.4 история E2EE восстанавливается также из защищённого кеша.
- Личные диалоги используют фото собеседника; комнаты и группы сохраняют свой аватар.
- ПКМ по сообщению → «Выделить сообщение» → флажки → «Переслать выбранные». До 100 загруженных сообщений за раз, в хронологическом порядке; при ошибке повторяется оставшаяся часть.
- ПКМ по чату → «Закрепить чат» или «Подписать контакт». Подпись доступна также в профиле пользователя, видна только текущему аккаунту на устройстве; имя в Matrix не меняется.
- Исправлено дублирование переписки при переключении с открытой информацией о комнате и перехват кликов невидимыми кнопками сообщения.

## Возможности клиента

- Фото, видео, аудио и файлы: отправка/сохранение до 500 МиБ, предпросмотр до 25 МиБ, очередь, прогресс, отмена и повтор. Загрузки файлов продолжаются при переходе в другой чат.
- Голосовые: настоящий MediaRecorder, индикатор уровня, пауза, продолжение, отмена и воспроизведение.
- Профили и настоящие аватары, изменение своего имени/фото, блокировка и разблокировка пользователя.
- Участники, приглашения, права администратора/модератора, исключение и блокировка, название/описание/фото комнаты, выход, публичный каталог. Канал создаётся с отправкой только администраторами.
- Пересылка, закреплённые сообщения, безопасное форматирование Markdown/Matrix HTML, mentions полным Matrix ID, typing и отметки прочтения. Для обычных комнат — поиск по серверной истории с переходом к результату; для E2EE — поиск в загруженном тексте.
- Несколько сохранённых аккаунтов, переключение с очисткой UI, список устройств, переименование и отзыв другой сессии с серверным подтверждением паролем, если оно требуется.
- Уведомления, звук, отключение уведомлений комнаты, масштаб 85–125%, фон, Windows tray и автозапуск. Кнопка закрытия окна завершает приложение; для работы в фоне используйте «Свернуть в трей».
- Реальные звонки 1:1 WebRTC: аудио/видео, mute, выбор устройств и демонстрация экрана, когда её поддерживает WebView. TURN берётся из стандартного Matrix API. Групповых звонков нет; реальный TURN и совместимость с Element ещё не проверены.
- Android bridge: Keystore, системный Back, разрешения микрофона/камеры/уведомлений, системное сохранение файлов и получение «Поделиться». Наличие исходников не означает проверки на телефоне; см. статус APK.

## Ключи, поиск и ПАПКИ

«Открыть зашифрованные комнаты» остаётся сбоку. Вход не требует recovery key. Доступны ручное включение E2EE, восстановление существующего secret storage, импорт и зашифрованный экспорт ключей. Новые комнаты/DM по умолчанию без шифрования; при создании комнаты можно явно выбрать E2EE. Шифрование и проверку целостности выполняет SDK. Автоматическое создание backup/cross-signing отключено. SAS/QR-верификации и создания новой серверной резервной копии в UI пока нет.

Поиск людей использует каталог Synapse по имени/фамилии/Matrix ID. ПАПКИ сохраняют названия, состав, порядок и фильтр непрочитанных локально для аккаунта. Их синхронизации между устройствами пока нет.

Токены и пароль SDK store не передаются в WebView. Windows использует DPAPI; Android — AES-GCM с Android Keystore. E2EE-история не пишется в открытый UI-кеш. Обычный кеш сохраняется после выхода. Конфигурация Synapse, PostgreSQL и TURN не менялась.

## Сборки и разработка

Актуальные NSIS/APK перечислены в [PROGRESS.md](PROGRESS.md). Старые сборки сохранены отдельно. Пакеты 0.5.2 имеют подпись для проверки обновлений; Windows Authenticode-сертификата пока нет. Архив исходников не содержит бинарников и токенов.

Нужны Node.js 24, Rust 1.99.1, Microsoft C++ Build Tools и Windows SDK; для запуска — WebView2 Runtime.

```powershell
npm ci
npm run tauri -- dev
npm run build
npm test
npm exec -w @matrixgram/client -- playwright install chromium
npm run test:e2e
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
npm run check:policy
./scripts/build-windows.ps1
```

`npm run dev` открывает веб-оболочку без Rust, поэтому вход в ней отключён. Тестовые данные подключаются только тестовым IPC. [Windows](docs/BUILD_WINDOWS.md), [Android](docs/BUILD_ANDROID.md), [проверки](docs/TESTING.md), [архитектура](docs/ARCHITECTURE.md), [безопасность](docs/SECURITY.md), [план](docs/ROADMAP.md), [звонки](docs/CALLS.md).
