# Сборка и установка Windows

## Требования

- Windows 10/11 x64 с WebView2 Runtime.
- Node.js 24 и npm.
- Rust 1.99.1 MSVC (версия закреплена в rust-toolchain.toml).
- Microsoft Visual C++ Build Tools, workload Desktop development with C++, Windows 10/11 SDK.
- Свободное место для Rust dependencies и промежуточных файлов: рекомендуется 10 ГБ и более.

Официальная инструкция: [Tauri Windows prerequisites](https://v2.tauri.app/start/prerequisites/#windows).

## Команды из корня репозитория

```powershell
npm ci
cargo test --workspace --locked
npm test
npm run build
npm run check:policy
npm run tauri -- dev
```

Подписанный updater-пакет использует постоянный ключ. Для этого проекта он подготовлен; на новой машине сначала восстановите его резервную копию либо задайте `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. Новый ключ не создают для каждой сборки. [Подробности](UPDATES.md).

Установщик:

```powershell
./scripts/build-windows.ps1
```

Скрипт временно оставляет только `rlib` для desktop, чтобы не выполнять лишнюю линковку мобильных staticlib/cdylib, и восстанавливает исходный Cargo.toml в `finally`. Не запускайте Android-сборку из этой же копии исходников одновременно со скриптом. Обычная команда Tauri build также допустима, но создаёт лишние выходные библиотеки.

По умолчанию EXE: `target/release/matrixgram.exe`, установщик: `target/release/bundle/nsis/MatrixGram_0.5.6_x64-setup.exe`. При заданном `CARGO_TARGET_DIR` ищите их в этой папке. Доступные фактически собранные файлы и контрольные суммы перечисляются в `releases/` и PROGRESS.md.

Установщик предназначен для текущего пользователя. При отсутствии WebView2 Tauri предлагает установить runtime. Для работы без интернета WebView2 нужно заранее установить отдельно.

Приложение и установщик на этом этапе не подписаны сертификатом разработчика. Проверка установщика, запуска, удаления и работы на чистой Windows 10 и Windows 11 — отдельные пункты проверки. В 0.5.2 добавлено подписанное обновление из GitHub Releases. Фактический переход между установленными версиями требуется проверить отдельно. В 0.5.1 подключены tray, autostart и системные уведомления. Их реальное поведение и установка/удаление требуют проверки на чистой системе; кнопка «Свернуть в трей» оставляет sync активным, закрытие окна завершает приложение.

## Нестандартное окружение этой разработки

Rust и минимальные MSVC/SDK-инструменты подготовлены локально в рабочей папке, вне системной установки Visual Studio. Из-за свободного места часть промежуточных файлов временно направлялась в отдельную папку на D:. После появления свободного места финальная сборка выполнена в `work/target` вне репозитория. Это локальная особенность окружения, не требование проекта. Пользовательские данные сервера и конфигурация Synapse не затрагивались.

Для preview без release-подписи используйте `./scripts/build-windows.ps1 -Unsigned`; такие файлы не публикуются в канал обновлений.
## Группировка Windows с 0.5.6 (кандидат)

Платформенный `tauri.windows.conf.json` включает неизменяемый identity-пакет и NSIS hooks. Android эти ресурсы не получает. При сборке `build.rs` запускает проверку публичных файлов и компилирует минимальный C# помощник встроенным .NET Framework compiler. MakeAppx/SignTool и приватный MSIX-ключ для обычной сборки не нужны.

```powershell
./scripts/prepare-windows-integration.ps1
./scripts/test-windows-integration.ps1
./scripts/build-windows.ps1
```

Для теста NSIS hooks нужен makensis (Tauri cache или установленный NSIS). Проверка не добавляет доверие, не запрашивает UAC и не регистрирует OS-пакет. Все поставляемые PowerShell scripts с русским текстом должны сохраняться как UTF-8 **с BOM** для Windows PowerShell 5. Вложенный процесс получает собственный inbox PSModulePath, чтобы не загрузить несовместимые модули PowerShell 7.

`windows/identity/` содержит только публичные неизменяемые файлы. Не запускайте `initialize-windows-identity.ps1` при выпуске новой версии и не увеличивайте identityVersion вслед за номером клиента. Этот скрипт предназначен для отдельного первоначального создания компонента и откажется перезаписать существующий. Ротация publisher/identity требует отдельного плана миграции.

Первая настройка требует явного согласия и UAC; временное peer trust удаляется. Обычные `/UPDATE` сохраняют привязку и сам каталог. После тихого обновления настройку можно включить из приложения. Полный статус и ручные проверки: [WINDOWS_PROCESS_GROUPING.md](WINDOWS_PROCESS_GROUPING.md).
