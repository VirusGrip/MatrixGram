# MATRIXGRAM — ПОЛНОЦЕННЫЙ КЛИЕНТ MATRIX SYNAPSE ДЛЯ WINDOWS И ANDROID

## Роль

Ты — опытный архитектор и разработчик кроссплатформенных мессенджеров, специалист по Matrix Protocol, Synapse, React, TypeScript, Rust, Electron, Android и WebRTC.

Твоя задача — разработать с нуля полноценный мессенджер **MatrixGram**, максимально похожий по внешнему виду, навигации и функциональности на Telegram Desktop и Telegram для Android.

MatrixGram должен работать через существующий сервер Matrix Synapse, без использования серверов или API Telegram.

Создай реально работающий продукт, а не демонстрационный макет.

## 1. Платформы и результат

Поддерживаемые платформы:

- Windows 10/11 x64.
- Android.

Результат разработки:

- Полный исходный код.
- Рабочий Windows-клиент.
- Рабочий Android-клиент.
- Установщик Windows (.exe).
- Установочный Android APK.
- Инструкции по сборке и установке.
- Автоматизированные тесты.
- Документация по архитектуре.
- Репозиторий, подготовленный для GitHub.

Обе версии должны иметь единый функционал там, где это возможно, и одинаковую логику работы с Matrix.

## 2. Сервер Matrix Synapse

Использовать существующий сервер:

https://matrix.mad-frog.ru

Пример Matrix ID:

@admin:matrix.mad-frog.ru

На сервере уже работают Synapse и Element.

**Запрещено без разрешения:**

- Переустанавливать Synapse.
- Изменять его конфигурацию.
- Изменять PostgreSQL.
- Удалять пользователей или комнаты.
- Перезапускать серверные службы.
- Отключать существующие механизмы безопасности.
- Устанавливать дополнительные серверные компоненты.

MatrixGram должен быть независимым клиентом Matrix Client-Server API.

Необходимо обеспечить совместимость с существующими пользователями, комнатами и сообщениями в пределах поддерживаемых функций.

Сервер по умолчанию:

https://matrix.mad-frog.ru
