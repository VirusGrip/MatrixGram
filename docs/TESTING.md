# Проверки

## Автоматические

`npm test` проверяет обработку событий: дедупликацию, порядок, текст с HTML, авторство редактирования, реакции, redaction и зашифрованные события.

`npm run test:e2e` запускает Playwright с тестовым IPC-модулем. Проверяются вход, открытие комнаты, отправка и повтор после ошибки, безопасное отображение текста, блокировка зашифрованной комнаты, мобильная навигация и тема. Ни один тест не подключается к вашему Matrix-аккаунту.

`cargo test -p matrixgram-core --locked` проверяет чистый HTTPS origin, запрет E2EE/unknown, UTF-8 лимит текста, SQLite, DPAPI на Windows и настоящие SDK-запросы к локальному wiremock: login, sync, send с txn, история, создание незашифрованной комнаты и TURN discovery. Тесты проверяют, что в зашифрованную комнату не выполняется PUT send.

`npm run check:policy` проверяет итоговые Cargo features и CSP, а не только строку версии в manifest.

Проверки, которые реально прошли в данной среде, перечислены в PROGRESS.md. Наличие теста в исходниках не означает успешный запуск.

## Проверка на вашем Synapse

Нужен отдельный тестовый аккаунт, уже созданный администратором. Клиент не создаёт пользователей и не меняет сервер. Пароль не нужно отправлять в чат или сохранять в репозитории: введите его в самом приложении.

1. Запустить EXE, войти, сверить комнаты со вторым совместимым Matrix-клиентом.
2. В новой тестовой комнате без E2EE обменяться сообщениями в обе стороны.
3. Проверить русский текст, emoji, переносы, ответы, правки, реакции и удаление только собственных тестовых сообщений.
4. Перезапустить приложение, проверить восстановление DPAPI-сессии и черновика.
5. Загрузить 3+ страницы истории; переключать комнаты; убедиться в отсутствии дубликатов и потери ввода.
6. Отключить сеть, открыть кеш, восстановить сеть, повторить неудачную отправку. Сверить отсутствие дубликата на сервере.
7. Открыть существующую зашифрованную тестовую комнату: нет ввода и нет попыток расшифровки. Проверить переход незашифрованной тестовой комнаты в E2EE через второй клиент.
8. Проверить выход и отзыв текущего устройства. Старые данные кеша остаются на диске — это известное ограничение.
9. Повторить на чистых Windows 10 и Windows 11. Отдельно проверить установщик, WebView2 и удаление приложения.

Звонки, вложения, уведомления и Android проверяются после реализации соответствующих пунктов roadmap.
