# Проверки 0.2.0

## Автоматические результаты

- 22 Rust unit/integration tests: HTTPS, fail-closed, SQLite/DPAPI, папки, настоящий SDK login/sync/send к wiremock, пагинация, user directory, повторное открытие DM, защита store паролем и старый формат сессии.
- Криптографические тесты генерируют настоящий Megolm event и зашифрованный экспорт через Matrix SDK crypto. Проверяется импорт с верным/неверным паролем, расшифровка body, отсутствие plaintext в открытом кеше и шифротекст исходящего запроса.
- 10 unit tests проекции: входные данные, дубликаты, HTML как текст, авторство правки, реакции, redaction и сохранение уже расшифрованного события.
- 10 Playwright-сценариев с отдельным IPC fixture: прежние сценарии, необязательное E2EE без мастера при входе, ошибка recovery key, поиск по фамилии/открытие DM и папки после перезагрузки.
- Production frontend build, Clippy с -D warnings, cargo fmt и check:policy.

Rust-тесты работают на локальном mock-сервере. Playwright заменяет только IPC адаптер тестового сервера. Тестовые данные не входят в production приложение. Проверка SDK-криптографии не подтверждает recovery key конкретного аккаунта или совместимость со вторым клиентом.

## Отдельная проверка на Synapse

Пароль и recovery key вводите в самом приложении, на отдельном тестовом аккаунте.

1. Обновить тестовую 0.1.0 до 0.2.0; проверить прежний аккаунт, комнаты и черновики без запроса ключа при входе.
2. Обменяться обычными сообщениями с Element; проверить историю, retry, ответы, правки, реакции и удаления только тестовых событий.
3. Найти пользователя по отображаемой фамилии, сверить полный Matrix ID, открыть DM дважды и убедиться в отсутствии дубля.
4. Создать папку, выбрать чаты, переименовать, изменить порядок, перезапустить приложение; удалить папку и убедиться, что чаты остались.
5. Открыть E2EE-комнату: до явного включения нет истории и отправки. Открыть без ключа: доступные события показываются, недоступные получают placeholder.
6. Проверить неверный recovery key, затем правильный ключ существующего secret storage. Не сбрасывать ключи или backup. Отдельно импортировать encrypted key export с верным/неверным паролем.
7. Обменяться E2EE-текстом с Element в обе стороны. Перезапустить приложение: ключи сохраняются без повторного запроса recovery key. Проверить права/доверие устройства на второй стороне.
8. Проверить установщик/удаление на чистых Windows 10 и 11, работу без сети и восстановление.

Новая версия не управляла окном пользователя после остановки Computer Use в прошлой итерации. Android, SAS/QR, медиа, звонки и push не объявляются проверенными.
