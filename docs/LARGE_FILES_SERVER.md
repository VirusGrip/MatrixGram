# Передача файлов до 500 МБ

Актуальное решение владельца: лимит клиента совпадает с сервером — 524 288 000 байт (500 МиБ) на файл. Ранее предложенное увеличение Synapse/proxy до 2 ГБ отменено. Серверные настройки не изменялись, SSH-подключения не выполнялись.

18 ноября 2026 авторизованный GET /_matrix/client/v1/media/config подтвердил `m.upload.size: 524288000`. Проверка не открывала SDK store и не меняла ключи устройств; реальные файлы и сообщения на Matrix-сервер не отправлялись.

Отправка более 25 МиБ идёт блоками по 1 МиБ через IPC. Rust подготавливает зашифрованный временный файл с эфемерным ключом в памяти, затем передаёт тело HTTP небольшими блоками. Для обычной комнаты передаются обычные байты, для E2EE — шифротекст и стандартное описание Matrix; событие отправляет Rust Matrix SDK. Проверка серверного предела выполняется заново перед загрузкой.

Скачивание идёт в файл, без base64 большого вложения в WebView. До замены выбранного файла проверяются размер и SHA-256 E2EE-шифротекста; повреждённое вложение не подменяет существующий файл. На Android применяется системный выбор документа и передача файлового дескриптора через JNI. Частичное SAF-сохранение очищается по возможности провайдера.

Предпросмотр, аватары и запись голоса остаются ограничены 25 МиБ; большой присланный файл сохраняется на устройство. Весь файл не помещается в JS/Rust-буфер. Нужны свободное место для временных файлов и работающий клиент; закрытие клиента во время передачи может оставить временные файлы. Возобновление после закрытия процесса не реализовано.
