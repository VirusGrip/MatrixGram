# Безопасность 0.5.2

E2EE возвращено по указанию владельца. SDK 0.19.1 имеет e2e-encryption и SQLite crypto-store; default features отключены. check:policy проверяет crypto features, запрет автоматического bootstrap backup/cross-signing и CSP.

## Необязательное шифрование

Вход не запрашивает ключи. e2ee_enabled по умолчанию false: до включения известные закрытые комнаты не загружают историю и не отправляют сообщения/receipt. SDK при этом подготавливает криптографическое устройство и обменивается публичными device keys. Новые DM/комнаты без шифрования; отдельный checkbox при создании комнаты явно добавляет m.room.encryption.

Запись проверяет состояние комнаты. Неизвестное состояние/ошибка блокирует отправку; plaintext fallback нет. SDK шифрует текст, вложения и call events автоматически. Проверка state и серверная запись не атомарны. Доступный зашифрованный файл, пересланный в обычную комнату, может быть скачан SDK независимо от включения доступа к E2EE-комнатам.

Recovery использует существующий secret storage/backup без reset_identity/recover_and_reset/recover_and_fix_backup. Импорт принимает зашифрованный экспорт Matrix/Element до 10 МБ. Экспорт SDK защищён отдельным паролем от 12 символов. Временные файлы содержат зашифрованные данные и удаляются после операции. Rust passphrase/key оборачиваются в Zeroizing, UI очищает поля; это не обещание полного стирания всех копий строк из памяти WebView.

SAS/QR и UI создания новой серверной резервной копии пока отсутствуют. Недоступный ключ отображается placeholder. Выход может сделать недоступными ключи, которых нет в backup/export; UI предупреждает об этом.

## Хранение и аккаунты

Случайный пароль защищает SDK SQLite/crypto store. Windows DPAPI связывает токен/пароль store/закрытые черновики с пользователем ОС. Android использует AES-256-GCM и неэкспортируемый ключ Android Keystore через JNI; runtime на телефоне ещё требуется проверить. Без системного vault plaintext fallback не создаётся.

Новые профили изолированы по UUID; legacy остаётся на прежнем месте. profiles.json хранит только метаданные. В WebView нет токена/пароля SDK store. При переключении UI и медиа-кеш очищаются, старый sync прекращается, загрузки отменяются, старые события отбрасываются по session key. Неактивные SDK-клиенты могут оставаться в памяти.

Расшифрованная E2EE-история не попадает в открытый UI-кеш; отображается в памяти. После явного подключения ключей UI подгружает доступную историю закрытых комнат для превью, не посылая read receipt; расшифрованное превью остаётся в памяти. Личные подписи контактов хранятся в LocalStorage отдельно для сервера/аккаунта, открытым текстом, не синхронизируются и не меняют серверный профиль. Они сохраняются при выходе/повторном входе этого же аккаунта.

Обычный кеш/названия комнат/папки открыты и сохраняются после logout. Выход не является безопасным стиранием. SDK migration старого формата покрыта тестом; обновление пользовательской установки отдельно не проверено.

## WebView, медиа и уведомления

HTTPS и TLS verification обязательны; HTTP допустим только локальным test fixture. Android verifier использует системный trust manager и соответствующий Kotlin AAR, проверка сертификатов не отключена. Секреты не пишутся в диагностический журнал; ошибки SDK заменяются сообщениями.

Matrix HTML преобразуется в React из разрешённых тегов, без dangerouslySetInnerHTML, event handlers/inline styles/scripts/embedded objects. Ссылки открываются нативно только с http/https. CSP допускает собственный JS, локальный IPC, blob/data изображения/медиа; удалённых скриптов/shell нет.

Вложения загружаются авторизованно через SDK, E2EE проверяет integrity. UI использует Blob URL и ограниченный memory cache без plaintext media disk cache. Лимит отправки/сохранения 25 МБ; SDK download получает ответ в память до финальной проверки размера, поэтому серверные лимиты тоже важны. Отмена upload не удаляет уже загруженные сервером media и не откатывает принятый event.

Включение текста системного уведомления — отдельная настройка, по умолчанию текст скрыт. Уведомления приглушаются при активном окне/первом sync/старых событиях; дубликаты ограничены sessionStorage. Приложение без push не гарантирует доставку в закрытом/усыплённом состоянии.

Системное сохранение требует выбора файла пользователем. Удаление другого устройства сохраняет UIA сервера и при необходимости запрашивает пароль; текущий device удаляется через logout. Search/roles/moderation ограничиваются правами Synapse. Сервер, TURN, PostgreSQL и службы не менялись.

Массовая пересылка ограничена 100 выбранными сообщениями. После частичного сбоя окно хранит transaction ID и завершённые отправки до закрытия; это не durable outbox. Закрытие останавливает следующие запросы, но не отзывает уже отправленный. Пересылка из E2EE в обычную комнату требует явного подтверждения.


## Обновления

Пакеты проверяются minisign, включая подписанную версию; stable SemVer должен увеличиваться. URL ограничен HTTPS GitHub-репозиторием VirusGrip/MatrixGram и соответствующим тегом. Текст release notes выводится как текст React. Удалённых JS/HTML обновлений без замены подписанного приложения нет. WebView не получает приватный ключ или GitHub token.

Windows updater запускает проверенный NSIS. Android дополнительно сверяет package ID, versionCode и сертификат установленного APK, использует только FileProvider для private cache updates и системное подтверждение. Неправильная подпись не включает установку. Невозможность сохранить текущий черновик, звонок и активные отправки блокируют установку. Операция через системный установщик ещё требует реальной проверки на устройствах; автоматические UI-тесты используют IPC fixture.

Первичная настройка Actions Secrets выполнена отдельной авторизацией GitHub CLI: доступных операций плагина для Secrets нет. Ключ updater зашифрован случайным паролем, пароль локально защищён DPAPI. Исходный Android signing key сохранён для совместимости тестовых установок; его сертификат сверен с APK 0.5.1. Публичные repo/CI-файлы не содержат закрытого ключа. Резервная копия вне Git обязательна для сохранения дальнейшей цепочки обновлений. [Полная схема](UPDATES.md).
