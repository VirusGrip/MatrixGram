# Карта ТЗ и дальнейшая работа

Исходный документ сохранён в `original-spec.ru.md` как исторический источник. Его указания про Electron/React Native и поддержку E2EE заменены последним запросом владельца: Tauri 2 + Rust SDK, без E2EE. Лицензия выбирается владельцем отдельно.

| Область | В исходниках 0.1.0 | Остаётся |
|---|---|---|
| Вход | пароль, HTTPS, ошибки, Windows DPAPI restore/logout | SSO/OIDC, UIA, несколько аккаунтов, управление устройствами |
| Комнаты | список, unread, приглашения/join, создание private/public с приглашениями | управление участниками и power levels, каналы, покинуть, профили/аватары |
| Текст | sync, кеш, пагинация, txn retry, reply/edit/redact/reaction | пересылка, форматирование, пины сообщений, receipt UI, typing UI, mentions |
| Интерфейс | 3 колонки, поиск чатов и загруженной истории, темы, local pin, виртуализация, мобильная компоновка | папки/архив, масштаб, обои, положение прокрутки между запусками, hotkeys |
| Данные | SDK SQLite, timeline SQLite, черновики, защита сессии Windows | durable outbox, очистка/лимит кеша, профили/медиа, Keystore Android |
| Медиа | отсутствуют, неподдерживаемый текстовый fallback | upload/download, preview, голосовые, видео, clipboard, drag-and-drop |
| Звонки | только Rust TURN discovery и тест | реальный WebRTC и Matrix signaling, Android permissions/lifecycle |
| Windows | собраны release EXE и NSIS x64, проверен экран входа на Windows 11 | установка/удаление на чистых ОС, подпись, трей, autostart, уведомления |
| Android | общий mobile entrypoint, responsive UI, иконки и инструкция | полный runtime, Back bridge, Keystore, APK, тест на устройстве, push |
| Сервер | только Client-Server API, default homeserver | серверная установка не требуется; push/MatrixRTC согласовываются отдельно |

## Ближайший порядок

1. Проверить установку/удаление Windows и вход на отдельном тестовом аккаунте; EXE/NSIS и локальные автоматические проверки уже получены.
2. Исправить найденные проблемы настоящего sync и restart до расширения функциональности.
3. Добавить файлы/изображения и нативные уведомления Windows, затем профили и участников.
4. Реализовать Android Keystore, back/lifecycle, собрать и проверить APK.
5. Реализовать и проверить звонки один на один через существующий TURN; затем голосовые и расширенные функции.

Полноценный релиз нельзя объявлять готовым, пока не проверены основные сценарии на реальном сервере, обеих платформах и второй стороне Matrix.
