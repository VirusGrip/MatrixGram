# План после 0.2.0

Исходное ТЗ хранится в original-spec.ru.md как исторический документ. Используется Tauri 2 с общим Rust-ядром. Последний запрос владельца вернул необязательное E2EE, добавил поиск пользователей и ПАПКИ.

| Область | В исходниках | Остаётся |
|---|---|---|
| Вход | пароль, Windows DPAPI, restore/logout, совместимость формата 0.1.0 | SSO/OIDC/UIA, несколько аккаунтов, управление устройствами |
| E2EE | ручное включение, SDK encryption/decryption, recovery key, импорт encrypted key export, защищённый store | проверка реального recovery и Element, SAS/QR, выбор шифрования при создании |
| Люди | поиск по display name / Matrix ID, открытие и повторное использование личного чата | реальные аватары, контакты, профиль |
| ПАПКИ | названия, состав, unread-only, порядок, редактирование и удаление, SQLite | синхронизация папок между устройствами |
| Текст | sync, история, кеш, retry txn, ответы, правки, redaction, реакции | форматирование, пересылка, typing/receipt UI, mentions |
| Комнаты | создание private/public, приглашения, join | участники, power levels, каналы, выход, профили |
| Медиа / звонки | только Rust TURN discovery | файлы, голосовые, реальный WebRTC, уведомления |
| Windows | сборка EXE/NSIS, базовый запуск 0.1.0 | установка/удаление и новая версия на чистых Windows 10/11, подпись, трей/autostart |
| Android | общий mobile entrypoint и адаптивный UI | SDK/NDK, Keystore, Back/lifecycle, APK, устройство и push |

Ближайший этап — отдельный тестовый аккаунт на реальном Synapse, совместимость с Element, обновление 0.1.0, восстановление ключей и проверка установщика. Затем вложения/уведомления Windows и Android. Серверные компоненты не устанавливаются без отдельного разрешения.
