# MatrixGram — прогресс

Дата: 30 октября 2026. Текущая версия: **0.3.0**, ранняя сборка.

## Изменения по примеру Telegram

- Компактный поиск, папки на левой полосе с действием **ПАПКИ**, строки чатов 68 px и сплошное синее выделение.
- Убраны большая шапка «Сообщения» и дублирующие фильтры. Ширина списка настраивается и сохраняется.
- Заголовок переписки 54 px, информация открывается по запросу. Неизвестное число участников больше не выводится как 0.
- Компактные группы сообщений, время рядом с текстом, короткая история снизу и плоская строка ввода. Тёмная палитра по присланному примеру, светлая тема сохранена.
- На мобильном экране папки доступны в горизонтальной строке. Исправлено перекрытие повторной отправки уведомлением об ошибке.
- Поиск пользователей, локальные папки и необязательное восстановление ключей из 0.2.0 сохранены. Вход не открывает мастер ключей; новые комнаты по умолчанию без шифрования.

Подробности оформления и проверок: [UI.md](docs/UI.md), [TESTING.md](docs/TESTING.md).

## Проверено

- **14 frontend unit tests** и **13 Playwright-сценариев** с тестовым IPC. Проверены отправка/retry, черновики, ключи, поиск, папки, группы сообщений, ширина списка, мобильная навигация и прокрутка 180 сообщений.
- Снимки при ширинах 1440, 1280 и 390 px, тёмная и светлая темы просмотрены. Снимки используют вымышленные данные, которых нет в production.
- **22 Rust tests**: SDK, Megolm, encrypted export, неверный пароль, ciphertext отправки, защищённое хранилище, старый формат сессии, user directory, DM и папки.
- Production frontend build, cargo fmt, Clippy --workspace --all-targets -D warnings и check:policy. Изменения Rust ограничены версией и User-Agent.
- Windows x64 EXE и NSIS собраны. Версия файла и встроенный frontend сверены, SHA-256 записан. Установка/удаление и запуск 0.3.0 в реальном аккаунте не проверены. Пользователь ранее подтвердил запуск 0.1.0 и показал работающую 0.2.0.

## Ограничения и непроверенные сценарии

- Реальные аватары, просмотр/отправка вложений, голосовые, WebRTC-звонки, уведомления/push, трей, автозапуск и несколько аккаунтов ещё не реализованы. Изображения пока отображаются именем файла.
- Реальный recovery key аккаунта, secret storage, обновление установленного клиента, обмен E2EE с Element и доверие устройства требуют проверки на тестовом аккаунте. Учётные данные и ключи пользователя не вводились.
- Нет SAS/QR-верификации, выбора E2EE при создании комнаты, экспорта ключей и создания новой резервной копии в UI. Недоступный ключ получает placeholder. При выходе есть предупреждение о возможной потере ключей, отсутствующих в backup/экспорте.
- Каталог пользователей зависит от правил Synapse. Папки локальны для текущей сессии, между устройствами не синхронизируются. Обычный кеш открыт и остаётся после выхода. Durable outbox нет.
- APK нет: отсутствуют Android SDK/NDK, Keystore и проверки Back/lifecycle на устройстве. Адаптивный UI проверен в браузере, Android-приложение не объявляется готовым.
- Установка/удаление и чистые Windows 10/11 не проверены. Конфигурация Synapse, PostgreSQL и TURN не менялась.
