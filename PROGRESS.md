# MatrixGram — прогресс

Дата: 29 октября 2026. Текущая версия: **0.2.0**, ранняя сборка.

## Добавлено по последнему запросу

- **«Открыть зашифрованные комнаты»** сбоку. Вход не требует recovery key и не открывает мастер восстановления. Доступ можно включить без старого ключа, восстановить по ключу/паролю secret storage или импортировать encrypted key export Element.
- E2EE SDK: расшифровка доступной истории и зашифрованная отправка после выбора пользователя. Новые комнаты/DM по умолчанию без шифрования. Автоматический bootstrap cross-signing/backup выключен; сбросы ключей не выполняются.
- Пароль SDK crypto-store и сессия защищены Windows DPAPI. Формат сессии 0.1.0 поддержан с сохранением device ID и прежнего кеша. Расшифрованная E2EE-история не записывается в открытый кеш; E2EE-черновики Windows защищены DPAPI.
- Поиск пользователей по имени/фамилии из профиля или Matrix ID через каталог сервера. В результате видны имя и полный ID, из него открывается существующий или новый личный чат.
- **ПАПКИ**: названия, выбор чатов, только непрочитанные, переименование, порядок, удаление. Папки сохраняются локально между запусками; удаление папки не удаляет комнаты.

## Проверено в этой среде

- **22 Rust tests**, включая настоящий Megolm, encrypted key export, неверный пароль, расшифровку и исходящий ciphertext; защита SDK store паролем, каталог пользователей, повторное открытие DM и сохранение папок.
- **10 unit tests** проекции событий и **10 Playwright-сценариев** интерфейса с тестовым IPC. Снимок папок и боковой кнопки просмотрен.
- Production frontend build, cargo fmt, Clippy --workspace --all-targets -D warnings, check:policy.
- Windows x64 release EXE и NSIS installer собраны. Старую 0.1.0 не перезаписывали. Новое окно через Computer Use не открывали; запуск 0.1.0 ранее подтвердил пользователь.

## Не проверено на живом сервере / ограничения

- Реальный recovery key вашего аккаунта, обновление установленной 0.1.0, обмен E2EE с Element и доверие устройства требуют проверки на тестовом аккаунте. Учётные данные и ключи пользователя не вводились.
- Recovery UI вызывает стандартный SDK recover без reset; полный серверный сценарий secret storage не воспроизводился в тестах. Проверен настоящий импорт encrypted export и Megolm.
- Нет SAS/QR-верификации и выбора E2EE при создании новой комнаты. Отсутствующий ключ показывается честным placeholder.
- Экспорт ключей из MatrixGram и создание новой резервной копии в UI пока отсутствуют. При выходе из E2EE-сессии есть предупреждение: ключи, не сохранённые в backup/экспорте, могут стать недоступны.
- Каталог возвращает только пользователей, доступных по правилам Synapse. Настройки сервера клиент не меняет.
- Папки локальны для текущей сессии аккаунта, не синхронизируются между устройствами. Обычный кеш открыт и остаётся после выхода. Durable outbox нет.
- APK нет: Android SDK/NDK отсутствуют; нужны Keystore, Back/lifecycle и устройство.
- Медиа, голосовые, WebRTC-звонки, уведомления/push, трей, автозапуск, multi-account ещё не реализованы.
- Установка/удаление и чистые Windows 10/11 не проверены. Конфигурация Synapse, PostgreSQL и TURN не менялась.
