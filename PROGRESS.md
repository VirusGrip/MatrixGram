# MatrixGram — прогресс

Дата: 29 октября 2026. Статус: **ранняя версия в разработке; не релиз**.

## Выполнено в исходниках

- Монорепозиторий: Tauri 2 + React 19/TypeScript + Zustand, Rust Matrix SDK 0.19.1, SQLite.
- Вход по паролю, публичное описание сессии без токена, восстановление/выход на Windows через DPAPI.
- Обычный Matrix sync с переподключением, комнаты, приглашения, история по 50 событий, кеш и дедупликация.
- Текст, ответы, редактирование, удаление, реакции; стабильный txn для повторной отправки в пределах процесса.
- Создание private/public комнат без E2EE; блокировка записи в encrypted/unknown в Rust.
- Адаптивный интерфейс, светлая/тёмная темы, локальное закрепление чатов, поиск в загруженной истории, черновики, виртуализация списков.
- Получение существующего TURN через стандартный Client API в Rust; звонки не реализованы.
- Документация, тесты и конфигурация Windows NSIS.

## Проверено в этой среде

- Прочитано исходное ТЗ из вложения прошлого чата, применены последние изменения владельца.
- `GET https://matrix.mad-frog.ru/_matrix/client/versions` отвечает и сообщает версии до v1.12. Только чтение, без авторизации.
- Production frontend build проходит.
- 9 тестов проекции Matrix-событий проходят, включая повреждённые входные события.
- 6 браузерных сценариев Playwright с тестовым IPC проходят. Снимки desktop/mobile визуально просмотрены.
- 15 Rust unit/integration tests проходят на Windows, включая DPAPI, реальные запросы SDK к wiremock, запрет E2EE/unknown и выход после отзыва токена.
- `cargo clippy --workspace --all-targets --locked -- -D warnings` и проверка форматирования проходят.
- Проверка Cargo features: E2EE и crypto-store Matrix отключены. CSP включена.
- Rust 1.99.1, локальные MSVC/Windows SDK-инструменты подготовлены. Первая попытка остановилась из-за отсутствующих инструментов и места C:. После освобождения места сборка на C: успешна; промежуточная попытка на D: была остановлена из-за медленного ввода/вывода.
- Успешно собраны release EXE и NSIS x64 installer. Первую сборку EXE запустили на Windows 11 Pro 10.0.26200: окно, WebView2 и экран входа отображаются, native IPC bootstrap завершён без ошибки, кнопка входа доступна.
- Проверка окна остановлена пользователем клавишей Esc; дальнейшее управление окном прекращено. Учётные данные не вводились. После последних исправлений выполняется финальная пересборка; её результат фиксируется ниже.

## Пока НЕ проверено / НЕ готово

- Вход, обмен, logout и restart на живом Synapse: тестовые учётные данные не предоставлялись, пользовательские данные не изменялись.
- Установка/удаление через NSIS и запуск на чистой Windows 10/11 не проверены. Повторная GUI-проверка финальной пересборки после Esc не выполнялась.
- `tauri android init --ci --skip-targets-install` выполнена и остановилась с ошибкой `Android SDK not found`. APK отсутствует. Нужны SDK/NDK и JDK 17+; установленная Java 8 недостаточна. Постоянная Android-сессия, системный Back и lifecycle ещё не реализованы/не проверены.
- Вложения, запись голоса, WebRTC, уведомления/push, трей, автозапуск, multi-account и управление устройствами.
- Совместимость со вторым клиентом, нагрузочные испытания, работа на чистых Windows 10/11.

## Ограничения

- Кеш переписок хранится открыто и остаётся после выхода; токен отдельно защищён DPAPI. Android не сохраняет токен на диск.
- Отправки ожидают реального результата API; неудачные можно повторить. После перезапуска процесса очередь повторов не восстанавливается.
- Поиск сообщений — только по загруженной истории. Пины чатов локальны для устройства.
- Форматированный HTML и вложения пока не отображаются как медиа.
- Лицензия, публикация на GitHub и подпись релиза ещё не согласованы/не выполнялись.
